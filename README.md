# Card with Animated Overlay

This project demonstrates a card design with an animated overlay effect using **HTML, CSS, and JavaScript**.  
It’s a beginner-friendly front-end project to learn animations, hover effects, and modern UI design.

---

## 🚀 Features
- Stylish card layout
- Smooth overlay animation on hover
- Responsive design (works on desktop & mobile)
- Easy to customize
